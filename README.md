# Gumoshabe Angel — Portfolio Website

A responsive dark-theme React portfolio for Gumoshabe Angel.

## Requirements
- Node.js 18+ (Node.js 20+ recommended)
- npm

## Run locally
1. Extract this project folder.
2. Open a terminal in the folder containing `package.json`.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment
```bash
npm run build
```
The production site will be created in the `dist` folder.

## Publish online
You can deploy this Vite project using Vercel or Netlify:
- Push the project to a GitHub repository.
- Import that repository into Vercel or Netlify.
- Build command: `npm run build`
- Output directory: `dist`

## Personalise before publishing
- Add a real portfolio URL after deployment.
- Add repository/demo links to each project when available.
- Confirm the exact official title of the ODE certificate.
- Confirm the certificate names and dates match the certificates.
- If you want a CV download button, add your final PDF as `public/Gumoshabe_Angel_CV.pdf` and add a link to it in the page.
